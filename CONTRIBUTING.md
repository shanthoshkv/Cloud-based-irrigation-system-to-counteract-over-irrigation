# Contributing to Cloud-Based Irrigation System

Thanks for helping. Small, focused changes are easiest to review.

## Getting set up

```bash
git clone https://github.com/shanthoshkv/Cloud-based-irrigation-system-to-counteract-over-irrigation
cd Cloud-based-irrigation-system-to-counteract-over-irrigation
```

## Check your change

```bash
# no firmware/app code here; this checks that links and referenced files in the *.md files exist
python .github/scripts/check_links.py
```

## Pull requests

1. Open an issue first for anything bigger than a bug fix or doc tweak.
2. Branch from `main`, keep the diff small, one concern per PR.
3. Make sure the check above passes and CI is green.
4. Describe what changed and why. Add a line to `CHANGELOG.md` under **Unreleased** for user-visible changes.

## Good first issues

Look for the [`good first issue`](https://github.com/shanthoshkv/Cloud-based-irrigation-system-to-counteract-over-irrigation/labels/good%20first%20issue) label. Comment on one to claim it.

## Questions

Use [Discussions](https://github.com/shanthoshkv/Cloud-based-irrigation-system-to-counteract-over-irrigation/discussions) for questions and ideas, Issues for bugs and concrete requests.
